유비 디렉터는 촬영한 영상·사진을 넣으면 인스타 릴스(세로 9:16)로 자동 편집해 주는 도구입니다. 시술뿐 아니라 일상·출퇴근·먹방·공간 만들기까지 카테고리를 골라 그 톤에 맞게 연출합니다. 자막·손글씨·효과음·BGM·색보정이 자동으로 들어갑니다. 유비가 직접 돌리는 법과, 시간이 없을 때 성준이 의도를 받아 틀을 갖추는 절차를 함께 담았습니다.

브라우저에서 열기 yubi-director.vercel.app

30초 요약

소스를 넣으면 → AI가 연출 방향 3가지를 제안하고 → 고른 방향으로 컷 구성·자막·손글씨 말풍선·효과음·BGM·색보정까지 짠 편집 계획을 만듭니다. 검토 화면에서 확인·수정한 뒤 “이대로 제작”을 누르면 1~2분 안에 완성본 mp4가 나오고, “지난 제작물”에 자동 저장됩니다. 설치 없이 브라우저만 있으면 됩니다.

맨 위 탭에 자유 모드 / 시리즈 모드 ✦ 두 개가 있습니다 — 시리즈 모드는 미리 짜둔 5편 스토리 중 하나를 고르면 컷·자막·BGM이 그 편의 대본 그대로 채워지는 모드입니다. 자세한 건 A1 참고.

두 가지 사용법

  • A · 유비가 직접 — 촬영 후 도구에 올려 3단계를 진행. 손에 익으면 5~10분.
  • B · 여유가 없을 때 — 유비는 소재·카테고리·하고 싶은 말만 5줄로 전달. 성준이 컷 리스트·자막·손글씨·필요한 소스를 담은 콘텐츠 틀을 짜서 도구까지 돌리고, 유비는 완성본만 확인.

아래 색 표기 — 유비가 하는 일 / 성준이 하는 일.

A

유비가 직접 만들 때

촬영 → 업로드 → 3단계. 완벽하게 준비하지 않아도 됩니다. 도구가 부족한 부분을 채우고, 마지막에 유비가 눈으로 확인하는 구조입니다. 시술이든 먹방이든 카테고리만 고르면 그 톤으로 알아서 편집합니다.

A0촬영할 때 챙길 것

편집을 염두에 두면 결과가 확 좋아지는 것들. 지키기 어려우면 그냥 찍어서 올려도 됩니다.

  • 세로로만 찍습니다 (9:16). 가로 영상은 위아래가 잘리거나 블러 배경이 들어갑니다.
  • 한 장면을 5초 이상 넉넉히. 도구가 한 클립에서 여러 컷(줌인 구간 / 다른 표정 구간)을 뽑아 쓰기 때문에 길게 찍을수록 유리합니다.
  • 무음이어도 괜찮습니다 — BGM이 자동으로 깔립니다. 손 떨림·흔들림도 그대로 올리세요, 연출에 반영됩니다.
  • 유형별로 조금씩 확보: 클로즈업 / 결과·전후 사진 / 고객 반응 / 거울 확인 / 손·도구 클로즈업 / 설명 셀카 / 이동·걷기 / 공간·풍경 / 음식 클로즈업. 카테고리에 맞게.

A1소스 입력 — “오늘 어떤 영상 찍었어요?”

시리즈 모드 ✦ — 상단 탭에서 시리즈 모드를 누르면 미리 짜둔 5편 스토리(IG_R01~05) 목록이 뜹니다. 편을 고르고 [이 편으로 시작하기 →]를 누르면 소스 유형·카테고리·분위기·길이가 자동으로 채워지고, [자유 모드]로 돌아가 아래 절차를 그대로 이어갑니다. 이때 컷 구성·자막·BGM은 그 편의 대본 그대로 쓰입니다 — AI가 새로 짜지 않습니다. 검토 화면(A3)에 “○○ 대본 그대로예요” 안내가 뜨면 정상 적용된 것. 단, 손글씨 주석은 시리즈 대본에 없어 넣고 싶으면 A3에서 직접 추가해야 합니다.
  1. 큰 칸에 말하듯이 적습니다. “트롤리 끌고 지하철 타고 출근하는 거 찍었어요. 도착해서 세팅하는 것도.” 이 정도면 충분합니다.
  2. 영상·사진을 업로드하고, 각 파일 옆 드롭다운에서 유형을 골라줍니다 (클로즈업, 이동·걷기 …).
  3. 소스가 부족하면 추가 소스 검색 — 영상(B-roll)은 도입·전환·분위기 보강용, 사진(분위기 참고)은 눈으로만 참고. 핵심 장면은 직접 찍은 걸로 채우는 게 좋습니다.
  4. 콘텐츠 카테고리를 고릅니다 — 시술 / 일상 브이로그 / 출퇴근 / 먹방 / 공간·오픈 / 손님 후기 / Q&A·정보 / 기타. 카테고리마다 편집 톤·효과음·색보정 성향이 다릅니다 (아래 표). 밑의 칸에 세부를 자유롭게 적을 수 있어요 (“눈썹 반영구” / “혼밥 파스타” / “간판 시공 D-7”).
  5. 분위기 · 영상 길이를 선택합니다. 길이는 짧게 15~20초 / 표준 20~30초 / 스토리 30~45초.
  6. BGM은 안 올리면 분위기에 맞는 무료 음원이 자동으로 들어갑니다. 직접 올리고 싶으면 오디오 파일 업로드.
  7. [연출 제안 받기].
업로드 없이 CapCut로 직접 편집하고 싶을 때는 파일을 올리지 말고 다음 화면에서 [편집 지시서 받기]를 누르면, 따라 하기만 하면 되는 CapCut 단계별 지시서(메뉴 경로·자막 문구·BGM 검색어)가 나옵니다.

A2연출 방향 고르기

AI가 이 소스로 만들 수 있는 릴스 3가지를 카드로 보여줍니다 — 제목, 첫 3초 훅 문구, 핵심 포인트, 예상 길이, 포맷(Before/After형·브이로그형·정보형·스토리텔링형·먹방/ASMR형), 난이도. 고른 카테고리 톤이 제안에 반영됩니다. 하나 눌러 선택하고:

  • 파일을 올렸으면 → [편집 계획 만들기] (도구가 자동 편집)
  • 직접 편집할 거면 → [편집 지시서만 보기]

A3검토하고 제작하기

여기가 핵심입니다. 제작 전에 반드시 이 화면을 훑어봅니다.

미리보기 스크러버

  • 시간 슬라이더를 움직이면 그 순간의 컷 화면 + 자막 + 손글씨가 세로 화면 비율로 합성돼 보입니다.
  • 색보정·슬로우모션·컷 전환은 여기서 안 보이고 실제 제작 때 더해집니다. 배치 확인용이에요.

샷 구성 (컷별 클립 바꾸기)

  • 각 컷 카드에 썸네일 + 드롭다운이 있습니다. 드롭다운은 지금 그 컷에 배정된 클립이고, 열어보면 업로드한 전체 소스 목록이 나옵니다 — 골라서 바로 바꿀 수 있어요.
  • 바꾸면 미리보기 스크러버와 실제 제작 결과에 바로 반영됩니다. 되돌리고 싶으면 다시 원래 클립을 고르면 됩니다.
  • 특히 시리즈 모드에서 유용합니다 — 대본의 장면 설명과 업로드한 소스 유형(클로즈업/이동·걷기 등 태그)을 자동으로 맞춰보지만 태그가 뭉뚱그려져 있어 완벽하지 않을 수 있습니다. 엉뚱한 컷에 엉뚱한 영상이 붙어 있으면 여기서 눈으로 보고 고치세요.

자막 편집기

  • 문구와 시작·끝 초를 직접 고칩니다. 줄을 추가·삭제할 수 있고, 비우면 제작에서 빠집니다.
  • 자막은 항상 한 줄로 나갑니다 — 긴 문장은 글씨가 자동으로 작아지니, 짧게 끊어 여러 줄로 나누는 편이 낫습니다.

손글씨 주석 편집기

  • 먼저 표현 유형을 하나 고르면 말풍선·색·장식·화살표가 한 번에 세팅됩니다 (질문 던지기 / 핵심 강조 / 콕 집어 지목 / 감성 한마디 / 마무리 CTA / 미니멀).
  • 그다음 필요하면 말풍선 모양·색·장식 글자(♡ ✦)·화살표·위치(가로·세로 %)·배경 판을 미세 조정. 오른쪽 미리보기에 즉시 반영됩니다.
  • 문구는 12자 이내로 짧고 강하게. 감정 영상이라면 1~3개면 충분합니다.

효과음

  • AI가 분기점마다 효과음을 얹습니다 — 도입 훅 · 큰 전환 · 결과/반전 공개 · 마무리. 목록에 초 · 종류(transition, shutter, ding …)가 나옵니다.
  • 모든 전환마다 넣지 않고 3~5개만, 같은 효과음은 3번 이상 안 씁니다. 카테고리 성향에 맞춰 골라집니다(먹방=zoom·ding, 공간·오픈=riser·impact 등).
  • 효과음은 검토 화면에서 수정 UI가 아직 없어 목록으로 확인만 합니다. 빼고 싶으면 성준에게.

제작

  • [이대로 제작] → 1~2분 → 완성본 재생·다운로드. “지난 제작물” 갤러리에 자동으로 쌓입니다.
  • 마음에 안 들면 [계획 다시 짜기](같은 연출로 재구성) 또는 [연출 다시 고르기](2단계로).

A!자주 걸리는 것

  • 원본 이미지에 글자가 박혀 있으면 최종본에도 보입니다 — 스토리보드 가이드 텍스트(“화면 하단 중앙”, “페이드인”)나 워터마크가 있는 컷은 깨끗한 버전으로 교체하세요.
  • AI가 컷 순서를 바꿀 수 있습니다 — 감정 회상형 연출은 컷을 재배치합니다. 스토리 순서(촬영 순서)를 지키려면 순차형 연출을 고르고, 검토 화면에서 자막이 맞는 컷에 얹혔는지 눈으로 확인하세요.
  • 제작은 최대 2분까지입니다. 아주 긴 영상은 스토리(30~45초)로 잡아도 그 안에 맞춰 압축됩니다.

B1유비가 넘기는 것 — 5줄이면 됩니다

완성된 기획이 아니라 재료만. 음성 메모로 말해도 되고, 아래 항목만 있으면 성준이 틀을 잡을 수 있습니다.

  1. 오늘 소재 한 줄 + 카테고리 — 무슨 콘텐츠인지. “출퇴근 — 트롤리 끌고 지하철” / “시술 — 이마라인 첫 상담 온 손님”
  2. 하고 싶은 말 / 느낌 — 왜 이걸 올리고 싶은지. “이동은 고단해도 이게 내 일상이라고, 담백하게”
  3. 찍어둔 것 — 있으면 파일 그대로 전송, 없으면 “없음”.
  4. 분위기 — 담백·솔직 / 감동·진솔 / 전문·신뢰 / 밝고 활기 / 정보·교육 / 셀프디스 유머 중 하나.
  5. 언제까지 / 급한지.

→ 아래 “인테이크 템플릿”을 카톡에 붙여 쓰면 됩니다.

B2성준이 짜는 콘텐츠 틀

한 장짜리 기획 프레임. 각 항목이 도구 입력값과 1:1로 대응하도록 만들어, 나중에 그대로 옮겨 넣기만 하면 됩니다.

틀에 들어가는 항목

  • 에피소드 코드 / 제목 — IG_R02 같은 번호 + 한 줄 제목.
  • 한 줄 콘셉트 & 훅 — 영상이 말하려는 것 한 문장 + 첫 3초에 뜰 자막.
  • 도구 입력값 — 소스 유형 태그 / 카테고리 + 세부 / 분위기 / 영상 길이 / 색보정 / BGM. (옵션 레퍼런스에서 골라 확정)
  • 소스 체크리스트 — ① 이미 있음(유비 전달) ② 추가 촬영 필요 ③ Pexels로 채움. 세 칸으로 나눠 명확히.
  • 컷 리스트 — 씬 번호 · 화면 내용 · 길이(초) · 연출(줌인/줌아웃/슬로모/고정) · 자막 · 손글씨.
  • 자막 전체 스크립트 — 초 단위, 한 줄씩, 시간 안 겹치게.
  • 손글씨 주석 1~3개 — 문구(12자) · 노출 초 · 표현 유형 · 위치.
  • 검토 체크리스트 — 제작 전 눈으로 볼 항목 (지시문이 자막에 안 섞였나 / 손글씨가 얼굴 안 가리나 / 컷 순서).

→ 아래 “콘텐츠 틀 템플릿”에 빈칸이 다 들어 있습니다.

의도 → 틀로 옮길 때 성준이 정하는 것: 유비의 “하고 싶은 말”을 훅 한 문장 + 자막 스크립트로 풀고, “느낌”을 분위기·색보정·BGM·연출 톤으로 번역하고, 소재에 맞는 컷 순서와 길이를 잡습니다. 유비가 확인할 수 있게 훅과 자막은 유비 말투 그대로 씁니다.

B3소스 채우기

  • 추가 촬영이 필요하면 — 성준이 “촬영 요청 카드” 한 장을 보냅니다. 무엇을·어떻게·세로로·몇 초. 틀의 소스 체크리스트에서 그대로 뽑아 씁니다.
  • Pexels 보강 — 도입/전환/분위기 컷은 성준이 도구의 “추가 소스 검색”에서 미리 담아둡니다. 검색어는 영어로 (eyebrow makeup closeup, calm skincare studio).
  • 둘 다 안 되면 — 가진 소스만으로 되는 짧은 버전(15~20초)으로 틀을 다시 잡습니다.

B4도구에 넣고 마무리

소스가 모이면 성준이 도구를 A1~A3 그대로 진행합니다. 검토 화면에서 AI가 만든 자막·손글씨를 틀 문서 내용으로 교체하고, 체크리스트를 확인한 뒤 제작.

누가 도구를 조작하나 — 두 가지

  • 성준이 끝까지 — 제작·검토까지 성준이 하고, 유비에게 완성본 링크만 전달. 유비는 보고 OK 또는 수정 한 줄.
  • 마지막만 유비 — 성준이 소스 + 틀을 준비해 두고, 유비는 도구에서 파일 올리고 연출 고른 뒤 검토 화면에서 “이대로 제작”만. 틀 문서를 옆에 띄워두고 자막만 대조하면 2~3분.

  • 완성본은 세로 1080×1920 고정. 제작 시간은 최대 2분.
